## 🚀 Características Principales

1. **Crawl Técnico y Arquitectura**:
   - Rastreo recursivo same-origin hasta 50.000+ URLs.
   - Detección de páginas huérfanas, cadenas de redirecciones, códigos HTTP y TTFB.
   - Auditoría estricta de Canonical, Meta Robots y Hreflang.
   - **Renderizado JavaScript nativo con Chromium** para SPAs.

2. **On-Page y Semántica**:
   - Estructura de encabezados H1-H6 y títulos con ancho estimado en píxeles.
   - Auditoría completa de imágenes (ALT, dimensiones, peso).
   - Enlaces rotos internos y validación estricta de **Schema.org** (JSON-LD).

3. **SEO Local (GEO Engine)**:
   - Validación de schemas LocalBusiness, PostalAddress y GeoCoordinates.
   - Consistencia NAP (teléfonos, emails y direcciones entre texto visible y schema).

4. **AI Engine Optimization (AIO / GEO / LLMO)**:
   - Detección y validación de /llms.txt y /llms-full.txt.
   - Control de acceso de bots de IA (GPTBot, ClaudeBot, PerplexityBot, etc.).
   - Auditoría de señales de confianza E-E-A-T.

5. **Asistente IA Integrado (BYOK)**:
   - Conexión con 9 proveedores (OpenAI, Anthropic, DeepSeek, Groq, Gemini) o **modelos locales gratuitos vía Ollama/LM Studio** sin compartir datos.
